# Victor H. Zendejas Lopez: research site

A static site: plain HTML, CSS and JavaScript, no build step. It is published with GitHub Pages from this repository.

Pages: `index.html` (home) and one page per simulation (`richtmyer-meshkov-single-shock.html`, `richtmyer-meshkov-2d.html`, `richtmyer-meshkov-3d.html`, `taylor-green.html`, `taylor-green-supersonic.html`). The pages share `site.css` and `site.js`.

Preview on your own computer: run `python3 serve.py`, then open http://localhost:8000 (Ctrl+C stops it).
The contact links and the LLNL release numbers are in the block marked `EDIT ME` at the top of `site.js`.
